# 🤝 Code of Conduct

**OmniPlay is for everyone who wants their files to play.**

</div>

---

## Our pledge

We want participating in this project to be a harassment-free experience for everyone,
regardless of age, body size, visible or invisible disability, ethnicity, sex
characteristics, gender identity and expression, level of experience, education,
socio-economic status, nationality, personal appearance, race, religion, or sexual
identity and orientation.

We pledge to act in ways that contribute to an open, welcoming, diverse, inclusive and
healthy community.

---

## What we expect

| ✅ Encouraged | ❌ Not tolerated |
| :-- | :-- |
| Being kind and patient with beginners | Insults, demeaning comments, personal attacks |
| Giving actionable, technical feedback | Harassment of any kind, public or private |
| Respecting differing viewpoints and experiences | Sexualised language or imagery, unwelcome attention |
| Accepting responsibility and apologising | Publishing others' private information without permission |
| Focusing on what is best for the project | Sustained disruption of discussions or reviews |

---

## Scope

This applies in every project space — issues, pull requests, discussions, commit messages,
code comments — and when representing the project in public.

---

## Reporting

Report unacceptable behaviour privately to the maintainer:

- **Email:** dbobmusicq@gmail.com
- Or use GitHub's [private vulnerability reporting](https://github.com/process-killed/omniplayer/security/advisories/new) if you prefer a channel that stays on GitHub.

Include what happened, where, and who was involved. Reports are read within **5 working
days** and kept confidential.

---

## Enforcement

| Severity | Response |
| :-- | :-- |
| **Correction** | Private message explaining the impact, with a request to adjust |
| **Warning** | Formal warning; no interaction with the people involved for a set period |
| **Temporary ban** | Temporary removal from all project interaction |
| **Permanent ban** | Permanent removal, for a pattern of violations or a single severe one |

The maintainer decides, documents the reasoning privately, and may consult other
contributors. Anyone enforcing may recuse themselves if they were involved.
